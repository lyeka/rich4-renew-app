# 无素材评测基础

阶段 1 提供可运行的 **Board 格式核心地图** `fixtures/maps/agent-lab.json`：16 个连通道路节点、1 块可购买/升级地块，纯 JSON，无外部地图包、贴图、音频或浏览器 DOM 依赖。`fixture.ts` 创建真实 Game，并提供仅测试使用的固定种子。

```sh
# 仓库根目录；先完成 game/ 的 npm ci
make fixture-check
```

`game/src/core/agent-fixture.test.ts` 验证两件事：

1. 真正的 Game.run() 在这张地图启动，进入真人回合 Ask，没有切为托管 AI。
2. 同一地图和录制的购买/升级回答调用真实规则，检查现金、产权、等级及 buy/build 事件，两次回放完全一致。

这不是 Agent 策略，也不是完整对局评测器；测试中固定回答只用于规则回放。地图使用引擎 Board 数据结构，不是原游戏 RawMap 素材格式，当前不能当作带贴图的 UI 城市包导入。

后续共享宿主接入后，本目录复用同一地图扩充卡片、多步、银行、小游戏、其他玩家事件和网络故障场景，再建立浏览器/无界面一致性及完整对局评测。当前两个核心测试不依赖缺失素材，不允许因素材不存在而跳过，也不声称已经证明小游戏或所有地图的规则一致性。真实城市素材测试和规模评测仍沿用 Roadmap 的后续验收。
